# 🧠 MindMate - AI Psychology Assistant

MindMate helps you transform negative thoughts into a positive mindset using AI.

> Your personal AI companion for mental well-being.

### 🔗 Live Demo
**Try it here:** https://muskan-mindmate-ai.streamlit.app

### ✨ Features
- Analyzes your negative thoughts
- Identifies cognitive distortions
- Suggests reframed positive thoughts
- Simple and private - no data is stored

### 🛠️ Tech Stack
- Python
- Streamlit
- Psychology + AI logic

### 🚀 How to Run Locally
```bash
pip install streamlit
streamlit run app.py
